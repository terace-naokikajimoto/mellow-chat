# faq.json 再生成プロンプト（テンプレ）

> 用途の違い：**サイトの事実が変わった**ときはこのファイル。**未回答ログから新しいQ&Aを足して育てたい**
> ときは [`grow-faq-prompt.md`](./grow-faq-prompt.md)。月1運用では「①育成（grow）→②事実反映（regen）」の順で回すと噛み合います。

サイトの最新情報を `faq.json` に反映し直すときに使う指示テンプレです。
`node tools/crawl-site.mjs` で `tools/site-content.json`（サイト全ページのコーパス）を更新してから、
以下を Claude（Claude Code など）に渡してください。

---

## 使い方

1. ターミナルで最新コーパスを取得:
   ```bash
   node tools/crawl-site.mjs
   ```
2. 下の「指示文」をコピーして Claude に貼り、実行してもらう。
3. 出てきた `public/faq.json` の差分（特に価格・納期・店舗情報）を**人が確認**。
4. 問題なければFTPで `public/faq.json` を上書きアップロード。

---

## 指示文（ここからコピー）

> `tools/site-content.json` は mellow-wet.jp の全ページを自動取得したコーパスです。
> これを唯一の情報源として、`public/faq.json` を最新化してください。ルールは厳守:
>
> 1. **事実はコーパスのみを根拠にする。** コーパスに無い数値・固有名詞・サービスを創作しない
>    （例: 存在しない「採寸シート」やクレジット一括払いなどを書かない）。一般的な選び方・
>    お手入れなどの助言は、サイトの事実と矛盾しない範囲なら可。
> 2. **既存の `faq.json` の構造・カテゴリ・トーンは維持。** スキーマは
>    `{ fallback, greeting, categories:[{id,label}], faqs:[{category,q,keywords,answer}] }`。
>    各 `faq` の `category` は `categories[].id` のいずれかにする。
> 3. **特に次の数値はコーパスの最新値に合わせる**: 価格帯、フルオーダー追加料金、納期
>    （春〜秋／冬で異なる）、店舗の住所・営業時間・電話番号、支払い・送料、電話番号。
> 4. リンクは実在URLのみ（`contact.html` であって `contact/` ではない、等）。
> 5. `keywords` は表記ゆれ（ひらがな/漢字/英字/言い換え）を各5〜10語。
> 6. 既存の良い回答は活かしつつ、事実が変わった箇所だけ的確に更新。新しく必要な
>    Q&A（コーパスにあるのにFAQに無い重要情報）は追加してよい。
> 7. 出力後、変更点を「価格/納期/店舗/その他」に分けて箇条書きで要約する。
>
> JSONとして妥当であることを `python3 -c "import json;json.load(open('public/faq.json'))"` で確認してから完了とすること。

## 定期自動化（任意）

毎回手で回す代わりに、`/schedule`（Claude Code のクラウド定期実行）で
「月1でクロール → faq.json 更新案を作成 → 結果を通知」まで自動化できます。
デプロイ（FTPアップ）は人の確認後に行う運用がおすすめです。設定したい場合はその旨を伝えてください。
